# 04. Ветвления и циклы

**Результат:** программа принимает решения, повторяет действия и заканчивает обработку
при конце ввода. Нужна глава [03](03-types.md).

## Условие и выбор

Условие `if` имеет тип `bool`. Число `1` не преобразуется в истину автоматически.

```csharp
int age = 20;
if (age < 0)
{
    Console.WriteLine("Некорректный возраст");
}
else if (age < 18)
{
    Console.WriteLine("Несовершеннолетний");
}
else
{
    Console.WriteLine("Совершеннолетний");
}
```

Порядок веток существенен: выполняется первая подходящая. Для интервала от 1 до 100
включительно нужно `value >= 1 && value <= 100`; запись `1 <= value <= 100` неверна.

Оператор `switch` удобен для конечного набора команд. Выражение `switch` возвращает значение:

```csharp
string command = "sum";
string description = command switch
{
    "sum" => "Сумма",
    "count" => "Количество",
    _ => "Неизвестная команда"
};
Console.WriteLine(description);
```

В `switch statement` ветка с инструкциями обычно заканчивается `break`, `return` или `throw`.
Неявного проваливания в следующую непустую ветку нет. `_ =>` в switch expression — запасной случай.
Развитые шаблоны будут в главе 17.

## Цикл и его границы

`for` подходит, когда известен счётчик:

```csharp
int total = 0;
for (int i = 1; i <= 5; i++)
{
    total += i;
}
Console.WriteLine(total); // 15
```

Перед каждой итерацией проверяется условие. После тела выполняется `i++`.
Инвариант этого цикла: перед итерацией с номером `i` переменная total хранит сумму
от 1 до `i - 1`. Это утверждение позволяет объяснить результат и найти ошибку границы.

`while` проверяет условие перед телом, `do ... while` — после, поэтому do выполняется хотя бы раз.
`foreach` последовательно получает элементы коллекции: например,
`foreach (char letter in "cat") Console.WriteLine(letter);`.

`break` завершает ближайший цикл, `continue` переходит к следующей итерации,
`return` выходит из метода целиком. В цикле while перед continue нужно обеспечить продвижение:
иначе значение, вызвавшее continue, может обрабатываться бесконечно.
В чужом коде встречается `goto`; он переносит управление к разрешённой метке.
Для обычного ввода понятнее цикл и return; специальные ограничения goto разбираются по справочнику.

## Конец потока и пользовательская команда

`Console.ReadLine()` возвращает строку либо `null`, если поток закончился.
Это не то же самое, что пустая строка после Enter. Обозначение `string?` допускает отсутствие строки;
подробно оно рассматривается в главе 06.

Полный пример для собственного `Program.cs`:

```csharp
long total = 0;
while (true)
{
    string? line = Console.ReadLine();
    if (line is null || line == "stop")
    {
        break;
    }

    if (!int.TryParse(line, out int value))
    {
        Console.WriteLine("error");
        continue;
    }

    total = checked(total + value);
}
Console.WriteLine(total);
```

`TryParse` возвращает успех и через `out` записывает число. Не пытайтесь использовать
полученное число при `false`. Здесь текст `abc` — ожидаемый неверный ввод, поэтому он
обрабатывается обычной веткой. Если гигантский поток переполнит `long`, checked выявит ошибку;
стратегию обработки исключений изучим в главе 09.

Для входа `10`, `abc`, `-3`, `stop` вывод — `error`, затем `7`.
Вводить строки нужно по отдельности. EOF можно проверить передачей файла стандартному вводу;
при интерактивном вводе Windows обычно используют Ctrl+Z и Enter.

## Проверка границ

Для задачи «сумма от 1 до n» проверьте `n=0`, `1`, `5`, `-1`.
Заранее определите контракт: здесь ноль даёт ноль, отрицательное n — ошибку.
Тест `n=5` один не выявит все ошибки. Условия `i < n` и `i <= n` отличаются
ровно одним элементом, который может потеряться незаметно.

## Практика

**04-A.** Напишите сумму от 1 до n через for. Вход задайте переменной.
Критерии: 0 → 0, 1 → 1, 5 → 15, отрицательное число → понятное сообщение.
Для результата используйте `long`.

**04-B.** Напишите приведённый сумматор по описанию, затем добавьте число успешно прочитанных значений.
Критерии: вход `10/abc/-3/stop` даёт сумму 7, количество 2 и одно сообщение об ошибке;
немедленный EOF — сумму 0 и количество 0. Знак `/` здесь разделяет строки, а не является вводом.

**04-C.** Ограничьте допустимое число диапазоном −1000…1000 и завершайте программу после трёх
ошибочных строк подряд. Успешная строка сбрасывает счётчик ошибок.
Критерии: `x/y/5/z/q/stop` не останавливается раньше stop; `x/y/z/5` завершается до обработки 5.
