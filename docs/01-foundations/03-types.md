# 03. Типы, числа и операции

**Результат:** вы выбираете тип данных, предсказываете арифметику и проверяете переполнение.
Нужна глава [02](02-syntax.md).

## Тип задаёт допустимые действия

`int` хранит целое, `bool` — `true` или `false`, `string` — текст.
Тип определяет диапазон, операции и правила преобразования. `int` — псевдоним `System.Int32`,
а не другой тип. `var count = 3;` тоже объявляет `int`: компилятор вывел тип из выражения.
Позже присвоить этой переменной строку нельзя. `var` не равен `dynamic`.

| Тип | Свойства | Типичное применение |
| --- | --- | --- |
| `sbyte/byte` | 8 бит, со знаком/без знака | Компактные значения, байты |
| `short/ushort` | 16 бит | Форматы и совместимость |
| `int/uint` | 32 бита | Счётчики, целые значения |
| `long/ulong` | 64 бита | Большие счётчики |
| `nint/nuint` | Размер платформенного указателя | Interop |
| `float/double` | Двоичная плавающая точка, около 6–9/15–17 значащих цифр | Измерения и расчёты |
| `decimal` | Десятичное представление, 28–29 значащих цифр | Суммы с десятичными долями |
| `char` | 16-битная кодовая единица UTF-16 | Работа с текстовым представлением |
| `bool` | Два логических значения | Условия |

Для `int` диапазон от −2 147 483 648 до 2 147 483 647. Значения `MinValue` и `MaxValue`
лучше использовать в проверках, чем перепечатывать границы. Выбор беззнакового типа сам по себе
не валидирует бизнес-правило «количество положительное»: ноль по-прежнему допустим.

## Литералы, константы и преобразования

```csharp
int count = 1_000;
long population = 8_000_000_000L;
double ratio = 0.5;
float scale = 0.5f;
decimal price = 19.90m;
const int MaxItems = 100;
int empty = default; // 0
Console.WriteLine(price * 3); // числовое значение 59.70
```

Суффикс `m` создаёт `decimal`. Без него `19.90` — `double`.
`const` требует вычислимое при компиляции значение. Понятие `readonly` относится к полям
и будет рассмотрено отдельно.

Неявное преобразование `int → long` сохраняет значение. Обратное обычно требует явного
cast: `int small = checked((int)large);`. Явность не гарантирует отсутствие потери данных.
Даже некоторые неявные преобразования к floating-point теряют точность.
Подробности: [числовые преобразования](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/numeric-conversions).

`(int)3.9` даёт `3`, а `(int)(-3.9)` — `-3`: дробь отбрасывается к нулю.
Это не правило округления денежных значений. Для округления используйте `Math.Round`
и явно выберите правило, например `MidpointRounding.ToEven`.

## Деление, округление и переполнение

```csharp
Console.WriteLine(5 / 2);        // 2
Console.WriteLine(5 / 2.0);      // 2.5
Console.WriteLine(5 % 2);        // 1
Console.WriteLine(0.1 + 0.2 == 0.3);    // False
Console.WriteLine(0.1m + 0.2m == 0.3m); // True

int value = int.MaxValue;
int wrapped = unchecked(value + 1); // int.MinValue
// int failed = checked(value + 1); // OverflowException
```

Сначала выполняется операция с типами её операндов, затем присваивание результату.
Поэтому `long total = count * price;` не спасает от переполнения умножения двух `int`.
Исправление — `checked((long)count * price)`.

`decimal` удобен для десятичных величин, но тоже имеет конечную точность: `1m / 3m` не
представляется точно. Валюта, число десятичных знаков и момент округления остаются правилами приложения.
Операции `decimal` при выходе за диапазон выбрасывают исключение и внутри `unchecked`.

`checked` действует на находящиеся в нём операции, а не автоматически на тело вызванного метода.
Переполнение целочисленного выражения, вычислимого при компиляции, обычно выявляется уже компилятором.

## Логика, приоритет и биты

`&&` и `||` применяют короткое замыкание: правый операнд вычисляется только при необходимости.
Выражение `denominator != 0 && numerator / denominator > 2` не делит на ноль.
`&` и `|` над `bool` вычисляют обе стороны; над целыми они выполняют побитовые операции.
`^` — XOR, а не степень; для степени служит `Math.Pow`.

`1 << 3` даёт `8`. В `flags & 4` проверяется конкретный бит; это не логическое «и»
двух условий. У `>>` и `>>>` различается заполнение старших битов для отрицательных чисел.
Подробные приёмы понадобятся в главе о enum и битовых флагах.

В `2 + 3 * 4` умножение выполняется раньше сложения. Скобки `(2 + 3) * 4` меняют результат.
Не смешивайте изменение переменной через `++` и её несколько чтений в одном сложном выражении:
разнесённые инструкции проще проверить.

## Разбор расчёта

Стоимость трёх товаров по `19.90m` равна `59.70m`. При скидке 10%:

```csharp
decimal subtotal = 19.90m * 3;
decimal total = Math.Round(subtotal * 0.90m, 2, MidpointRounding.ToEven);
Console.WriteLine(total); // числовое значение 53.73
```

Текстовое представление точки или запятой зависит от культуры; глава 06 закрепит формат вывода.
Запуск примера: `dotnet run --project examples/Foundations -- 03`.

## Практика

**03-A.** До запуска предскажите `7 / 3`, `7 / 3m`, `-7 % 3`, `(int)2.9`.
Критерий: объяснены тип и значение каждого результата, а не только скопирован вывод.

**03-B.** Рассчитайте заказ: цена `125.50m`, количество `4`, скидка `15m` процентов.
Округление итоговой суммы — два знака, ToEven. Критерий: `426.70`.
Проверьте скидки 0 и 100, количество 1. Проверку неверных входов добавите после главы 04.

**03-C.** Для `int count = 50_000; int price = 50_000;` получите точное значение
`2_500_000_000` типа `long`. Покажите вариант, где `checked` обнаруживает ошибку,
и вариант, где преобразование до умножения её предотвращает.
